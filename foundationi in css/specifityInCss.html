CSS Specificity Practice Activity

This paragraph is styled using multiple CSS rules:
- The element selector (p) sets the base color to blue and font size to 16px.
- The class selector (.custom) changes the color to green and font size to 18px.
- The ID selector (#special) sets the color to purple and font size to 20px.
- Finally, the inline style overrides everything, setting the color to red and font size to 22px.
